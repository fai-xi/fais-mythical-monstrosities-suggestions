# 🌙 Fai’s Mythical Monstrosities Suggestions

Welcome!  
This repository is for **ideas and feature suggestions** for *Fai’s Mythical Monstrosities*.

If you have an idea for:
- New Fakemon or variants
- Moves, abilities, or mechanics
- Events (Blood Moon, structures, encounters, etc.)
- Balance tweaks or QoL improvements

You’re in the right place ✨

---

## ❗ What this repo is NOT for
Please **do not** submit:
- 🐛 Bug reports or crashes  
  → Please use the **issues repo** instead!  
🐞 [Issue Tracker](https://github.com/fai-xi/fais-mythical-monstrosities-issues)
- ❓ Tech support or setup help
- 🚨 Urgent problems
- 📦 Modpack or redistribution requests
- 💰 Licensing or monetization questions

---

## ✅ Before submitting
Please:
1. **Search existing issues** to avoid duplicates!
2. Keep suggestions **clear and focused**!
3. Understand that **not all ideas will be added**
4. Be respectful, this is a creative space

---

## 🎨 Creative freedom notice
By submitting a suggestion, you understand that:
- Ideas may be adapted, changed, merged, or declined
- Submission does **not** guarantee implementation
- Credit may be given, but is not guaranteed
- Similar ideas may already be planned internally
